# Student Task API

A small FastAPI project to manage student tasks (create, read, update, delete).

## Tool Used
Cursor (model: Grok 4.6 Medium)

## How to Set Up
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

## How to Run
uvicorn main:app --reload

## How to Test
pytest
